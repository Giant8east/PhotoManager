# PhotoManager

阅读适配模式由 PhotoTransform 统一计算初始比例：原始尺寸为解码图片的 1:1，匹配宽度/高度按对应视口边长等比例缩放，匹配屏幕取两者较小值；初始比例限制为 0.1～10 倍。绘制、拖动边界与双击缩放使用同一比例基准，离屏后恢复当前模式的初始大小。连续纵向阅读保持匹配宽度；原始尺寸不代表原文件全分辨率解码，高清分块加载尚未实现。

`reader/PhotoViewerPageView.kt` 是单页状态容器，持有 Coil 请求、Painter 加载状态、失败重试、PhotoTransform 和注册生命周期；`PhotoViewerImage` 仅消费 Painter 与变换对象绘制。布局管理器提供实际可见范围，单页完全离开视口后恢复初始适配及居中位置，再次进入时不执行重置；仍部分可见时不重置。不可见不等于销毁，不取消相邻页预加载；销毁组合时由 Coil 释放请求订阅并解除变换注册。真机加载重试、切页与方向变化仍待验收。

阅读图片由 Coil 解码、Canvas 绘制：先计算完整图片变换后的矩形，与每页视口求交，再反算可见源区域；通用 Painter 通过完整图片变换与目标交集裁剪实现等价绘制，保留动画 Painter 能力，不将动图强制转换为静态 Bitmap。取消对满屏图片节点整体 graphicsLayer 缩放，避免上一页放大内容越过页面范围；加载成功直接同步图片几何，主动跳页取消旧缩放动画。页面离屏恢复由单页容器管理；此绘制方案不实现高清分块解码。

图片阅读页按职责组织在 `pages/photoviewer`：根目录保留 `PhotoViewerPage` 和 `PhotoViewerViewModel`；`reader` 管理图片、手势与分页布局，`edge` 管理边缘效果及绘制，`components` 放置操作栏、顶部信息和设置菜单，`system` 负责 Android 窗口与按键能力。`PhotoTransform` 保留在 `reader/PhotoViewerImage.kt` 中。

设置页持续显示已同步相册数量，同步时在数量后显示加载动画与“同步中”。导入、移除和手动同步共用可取消任务，右下角按钮同步时切换为停止图标；停止后保留已提交的相册，下次同步重新扫描。

设置页提供居中标题、返回图标与独立的顶部栏底色。系统明暗主题切换保留当前页面（不包含进程重启恢复）。目录同步按相册逐个提交事务，Room Flow 随提交逐步更新列表；已完成的相册不会因后续目录扫描失败而回滚。

页面导航统一提供 300 毫秒水平转场：入栈从右侧进入，返回时从左侧进入。

导航宿主始终占满窗口；普通页面在各自页面容器内避让系统栏和屏幕缺口，阅读页按阅读配置处理全屏与刘海布局，不显示顶部栏。阅读配置加载后才应用窗口，设置更新不反复恢复窗口。屏幕方向与主题切换保留当前页面，不包含进程回收后的导航恢复。
顶部安全区域单独使用深色主题色，顶部栏使用工具栏色；底部安全区域与正文共用主题背景色。默认使用固定主题配色，不跟随壁纸动态取色。图片阅读区域固定使用深灰色背景。

阅读互动组件 PhotoViewerControls 统一承载底部进度条与右下角播放按钮。单击页面切换显示，3 秒无操作后以 150 毫秒位移动画隐藏；拖动时暂停隐藏，松手定位并重新计时，从右至左阅读反转进度条方向。自动播放状态由阅读页面维护，组件负责计时；页面在尝试越过末页时统一停止播放，允许在末页启动，隐藏按钮继续播放，打开菜单暂停计时，尝试越过末页后停止。菜单只保存间隔，默认 3 秒。顶部信息层已显示电量、页码和时间。

阅读偏好使用 Kotlin Serialization 和类型化 DataStore 保存整份 JSON 配置；菜单枚举携带中文标题，存储保存英文枚举值。开发阶段不迁移旧 Preferences 阅读配置，首次使用采用默认设置。配置文件无法反序列化时，DataStore 会将损坏文件替换为默认阅读配置；普通 I/O 错误不按配置损坏处理。

相册详情页画廊按 EhViewer 的 120dp 目标列宽选择合适列数，图片区域宽高比为 0.667；原图宽高比严格介于 0.5～0.8 时居中裁剪，其余完整显示，下方显示从 1 开始的索引。详情页与阅读页共用完整图片元数据列表 Flow，按相同名称顺序查询，并通过 distinctUntilChanged 过滤相同结果；缩略图仍由 LazyVerticalGrid 按需组合与加载。详情网格使用 photo.id 作为 key，缩略图按布局约束采样并仅显示动图首帧。

PhotoManager 是一款基于 Kotlin + Jetpack Compose 的 Android 本地图片管理应用，直接读取系统 MediaStore，并使用 Room 保存收藏、标签和应用内整理信息。

当前阶段：功能开发与真机验收；P0 编译、生命周期与窗口基础已通过用户验收。

ViewModel 统一规范见 AGENTS.md：Compose 页面状态使用 mutableStateOf 配合 private set 对外只读，派生状态使用 val getter；分页及配置等已有 Flow 保留只读流接口。数据观察任务由 ViewModel 管理，页面调用普通动作方法，不引入额外 ViewModel 基类。

- Kotlin + Jetpack Compose
- MVVM：UI -> ViewModel -> Data

## 相册数据查询

相册列表通过 Room Flow 持续更新，分组筛选、标题搜索和排序由 SQLite 执行。

排序字段使用 AlbumSortField 枚举，Data 层组装统一 SQL 模板，DAO 使用 @RawQuery 执行并观察相册表。列名和升降序来自固定选项，分组 ID 和搜索词使用参数绑定；修改时间未知的相册始终排在最后。

目录导入在数据库事务中按唯一目录路径查询：新目录由数据库生成 ID；已有目录更新名称、封面和图片数量，保留 ID、分组及排序，并刷新目录修改时间，不删除关联图片记录。

标题搜索使用原始关键词，保留首尾空格；空字符串显示当前分组全部相册，纯空格按实际内容匹配。SQL LIKE 中的特殊字符按字面匹配。

相册时间采用文件提供方返回的目录最后修改时间，字段为 modifiedAt，保存 UTC ISO 8601 字符串，展示为 yyyy/MM/dd HH:mm。每次读取目录时刷新；未提供有效时间则保存 null，未知时间始终排在最后。分组仍使用 createdAt 表示 App 内创建时间。目录修改时间不保证反映全部子图片的变化，不作为跳过图片扫描的依据。

文件时间由 SAF DocumentsContract 的 COLUMN_LAST_MODIFIED 读取，按毫秒转换为 ISO 8601 保存；界面显示到分钟，排序使用完整时间。MediaStore 的 DATE_MODIFIED 单位是秒，若使用必须单独转换。

分组操作由 `GroupData` 管理，支持创建、重命名和删除。名称非空校验由 UI 负责；重命名保留分组 ID，删除分组通过外键 SET NULL 将相册移出分组，不删除相册或真实文件。分组和相册列表通过 Room Flow 更新，当前分组被删除后返回全部相册。编辑与删除的页面入口尚待接入。

相册列表新增 Paging 3 查询链：Room `PagingSource` → `Pager` → `Flow<PagingData<AlbumEntity>>`，默认页大小 30、预加载距离 10。原有 `Flow<List<AlbumEntity>>` 查询保持不变，当前页面仍使用原查询，分页 UI 后续接入。
相册页交互组件拆为 AlbumActionFab、AlbumSortButton 和 AlbumGroupDrawer，各自维护组件交互状态。FAB 提供图标操作及删除确认、移动分组选择；排序按钮打开底部菜单并更新查询；分组抽屉从左侧打开。

目录导入管理页的实施方案见 document/SettingPage实施方案.md，使用 SAF OpenDocumentTree 选择目录，持久化授权后递归导入所有含图片子目录。

设置页同时展示扫描目录数量和有效相册总数；有效相册以成功同步、目录可访问且包含图片为准，失效、空目录和扫描失败不计入。

FAB 展开状态由 AlbumPage 控制；删除确认和分组选择使用局部 DialogStack 的 show/pop API，DialogHost 只显示栈顶弹窗，系统返回先关闭当前弹窗。

阅读画布保持边到边布局；非全屏时系统导航按钮透明叠加在画布上，阅读期间关闭三键导航栏的对比度遮罩，退出后恢复。普通页面的顶部安全区底色仅占顶部 Insets 高度。

所有导航页面统一使用独立 PageContainer：完整窗口背景、安全区底色和正文一起参与转场；普通页面正文避让系统栏，图片页正文边到边。容器不修改全局导航宿主尺寸。

启用音量键翻页后，每个按下事件切换一张图片，长按跟随系统重复事件连续翻页；松开停止，不改变系统音量。按键采用无动画定位，避免连续翻页动画冲突。

阅读页背景始终占满窗口，非全屏仅内部图片视口避让系统栏及刘海并裁剪；全屏图片铺满窗口。首页返回将任务移到后台，系统仍可能回收进程。导航条目支持独立 PageTransition 策略。

宿主统一使用透明系统栏，Android 10 及以上关闭系统栏对比度遮罩；安全区底色由页面容器绘制并参与转场，系统图标仍由系统叠加。

已移除临时三色转场验证配色，所有普通页面统一使用主题。

## 明暗配色

采用 EhViewer 普通亮色和暗色主题的基础配色，不包含其纯黑主题。浅色顶部栏 #009688、顶部安全区 #00796B、正文及底部安全区 #FFFFFF；暗色顶部栏、正文及底部安全区 #323232、顶部安全区 #212121。浅色强调色 #E040FB，暗色强调色 #009688；内容容器分别使用 #F5F5F5、#3A3A3A，分隔色分别为 #20000000、#20FFFFFF。

Theme.kt 将传统 Material 主题角色映射到 Compose Material 3，补齐容器、文字、边框及错误颜色，关闭动态取色及表面色调叠加。LocalStatusBarColor 单独提供安全区背景，由 PageContainer 绘制并随页面转场。阅读画布固定 #303030，信息文字固定白色。Material 3 组件的样式与状态效果仍由 Compose 提供，并非复刻 EhViewer 的传统 View 控件。
系统栏背景保持透明，底色由页面容器绘制；不再根据背景亮度动态切换系统栏图标样式，避免窗口级判断覆盖设备默认行为。

阅读页音量键、自动翻页共用集中边界方法；Pager 使用原生拖拽翻页，局部禁用越界拉伸。

阅读页直接持有 PagerState，上一张、下一张和指定页跳转作为页面内部方法，不再使用 PhotoViewerState 包装。ViewModel 负责数据及持久化，PhotoViewerSystemController 负责 Android 窗口和系统按键能力。

系统栏透明背景与对比度遮罩统一由 MainActivity 配置；阅读控制器不再重复保存、设置或恢复导航栏颜色及对比度属性。

屏幕常亮仅由阅读页按配置开启，其他页面不启用；退出阅读页直接清除 FLAG_KEEP_SCREEN_ON，不保存原始窗口 flags。

阅读交互分阶段整改方案见 [PhotoViewerPage 实施方案第 12 节](document/PhotoViewerPage实施方案.md#12-借鉴-ehviewer-的阅读交互实施方案2026-10-19)，依次处理索引与翻页、手势边界、连续纵向阅读、控制栏、系统能力与生命周期。

阅读页从详情入口取得相册 ID 和初始索引。ViewModel 用 null 表示 Room 首次结果尚未到达，由页面外层显示加载提示；取得完整 PhotoEntity 列表后才创建阅读布局，页数直接取列表长度。Reader 直接按索引提供每页图片，不判断文件存在性、不提供记录占位；图片打开与解码由图片组件处理。当前页变化立即请求保存 Room 阅读进度，音量键和自动翻页均无动画。详情网格使用完整图片索引，相册库保留原查询方式。手势与连续纵向布局已接入，仍需真机验收。

阅读页通过 apply(settings) 统一应用全部窗口和按键设置，包括系统栏显隐；设置变化会重新应用全屏状态。自动播放由独立按钮管理，不更新 settings；退出阅读页恢复窗口。

阅读页时间和电量由 PhotoViewerOverlay 内的 produceState 每秒读取一次：时间读取系统当前时间并显示到秒，电量通过 BatteryManager 获取。退出组合时自动取消循环，不再通过 Data 和 ViewModel 转发广播数据。

阅读进度条参考 EhViewer Gallery 的固定暗色样式：面板 #424242，行高 48dp、两侧数字最小宽 32dp，按总页数字数与字体缩放扩展并保持单行，12dp 青绿色圆点、2dp 细轨道与青绿色已读部分；不随系统明暗主题切换。

阅读顶部信息层参考 EhViewer GalleryHeader，电量靠左、页码居中、时间靠右，边距 12dp；非全屏避让状态栏，全屏按实际刘海矩形避让；左右信息避让后，页码在剩余可用区域重新居中，三个显示开关独立生效，文字采用黑色阴影增强对比度。顶部信息不跟随底部操作栏自动隐藏。

阅读信息层按页面最终铺满窗口的坐标计算刘海避让，不使用导航转场中的 positionInWindow 回写布局，避免页面滑入时信息突然重新定位。

顶部信息层以页面最终铺满窗口的坐标计算刘海避让，不读取导航转场中的 positionInWindow；首次组合直接读取当前时间和电量，避免空内容变为实际内容后再次改变避让布局。

电池图标参考 EhViewer：每秒读取真实电量和充电状态，充电且未满电时每 200 毫秒增加 2% 图标填充并循环；百分比保持真实值，停止充电或满电后恢复真实填充。未充电且电量不超过 15% 时，图标和百分比使用警告色，组件离开组合后取消动画。

自动播放按配置间隔持续循环，进入末页后保留一个间隔，再次尝试下一页时触发独立圆弧边缘反馈并停止。反馈随阅读方向显示在左、右或底边，不拉伸图片；菜单及拖动暂停计时，组件退出自动取消循环。边缘反馈使用 Compose Canvas 实现 EhViewer 式大圆裁剪形状，固定 #339E9E9E，300ms 拉出、600ms 减速回缩；拉动量采用时间驱动，不复制原 GL 实现逐帧累加带来的刷新率差异。

阅读手势统一在固定视口接收，关闭 Pager 内置触摸处理，避免移动图片坐标与两套手势竞争造成翻页抖动。每次手势只建立一个 PagerState.scroll 会话，按“收回边缘、图片平移、页面滚动”顺序消费距离；仅对应方向确实无法继续滚动时，剩余距离才驱动圆弧。松手按连续页位置与起始页的距离决定目标：超过页面间隔与触摸阈值中的较大值即完成一页切换，否则回位，以 220ms 非弹性动画落定，不再依赖 Pager 原生手势的内部位移记录。双指及其剩余单指不驱动翻页。图片惯性平移及惯性撞边反馈已接入，尚待真机验收。

双击参考 EhViewer，在原始尺寸、匹配宽度、匹配高度、较大适配比例两倍四个候选档位中循环：实际比例限制到 0.1～10 后排序，选择比当前比例大超过 0.01 的下一档，没有则回到最小档。档位换算为相对于初始适配的倍数，捏合也使用相同的实际比例限制。围绕点击点执行 300ms 先快后慢动画，缩小时按图片边界自然调整，不强制偏移归零。图片尺寸仍来自当前解码的 intrinsicSize，不代表原文件像素尺寸或新增高清细节；分块解码另行实施。手势统一由固定视口识别，按下中断缩放动画。

阅读交互参考 EhViewer 拆分：PhotoViewerPager 作为统一入口组装固定视口；PhotoViewerGestureRecognizer 识别单击、双击、长按、单指拖动和双指缩放；PhotoViewerPagerLayoutManager 管理页面排列、距离分配、落页、缩放和主动越界模拟；PhotoViewerEdgeEffect 保存拉动状态并执行释放回缩，PhotoViewerEdgeView 使用 Canvas 绘制圆弧。图片几何与平移限制仍由 PhotoTransform 负责。手动越界和主动越界共用效果，保持 300ms 模拟拉动、600ms 回缩和 220ms 落页；离开页面或更换阅读方向时取消旧任务。此拆分不引入 OpenGL，图片惯性由布局管理器独立任务管理。

阅读边缘反馈现为左、右、上、下四个独立效果，角落斜拖可同时显示相邻两边，反向拖动分别收回，松手分别回缩。阅读轴优先交给图片平移和相邻页，仅相册首尾的剩余距离触发该轴反馈；另一轴仅在图片实际可平移时反馈，避免适配留白误触发。已通过单元测试与 Android 测试源码编译，真机待验收；惯性与 onAbsorb 已接入，完整边缘状态机已接入，尚待真机验收。

手动翻页落定和主动跳页完成后，布局管理器直接复原非当前页的缩放及偏移，不只依赖单页可见性重组；拖动中仍部分可见的页面保持原状，取消或中断的落页不提前复原。

## 页面主数据状态

相册库、相册详情、设置和阅读页统一使用 `PageState`：首次加载和重试为 `Loading`，所需数据全部到达后一次交付 `Content`，无主内容时居中显示 `Message`。正常空结果不显示重试，读取失败显示具体原因（无原因时使用资源兜底）并支持重试；重试取消旧观察，切换查询不会复用旧条件。公共加载、提示和重试文案提供英文与中文资源，`UiText` 在 Compose 中解析。

详情联合观察相册和完整图片索引，不以导航实体回退展示；观察只交付有效内容，刷新移除记录产生的末尾通知不覆盖画面，由刷新结果提示并返回，不展示相册缺失或空图片提示；阅读页等待图片索引与阅读配置，配置直接订阅 DataStore 自身的缓存与读取流，使读取异常可以传到页面并重新订阅。设置页没有目录仍为正常内容。刷新、同步失败保留已有内容，详情删除期间显示 Loading；主动删除及空目录刷新仍以 Toast 提示并返回。单张图片的解码、重试继续由单页组件负责。各 ViewModel 直接继承 AndroidX ViewModel，通过 mutableStateOf 与 private set 暴露主状态。

本次不调整数据库、同步算法或导航作用域。公共状态转换通过可控 Flow 单元测试验证；明暗主题、中英文、真机居中布局及删除返回交互仍需设备验收。

相册详情 ViewModel 通过 Hilt 辅助注入固定的 albumId 和 albumPath，创建时开始观察，无需页面调用 load。菜单刷新和错误页重试统一调用 refreshDirectory；刷新和删除由 ViewModel 在 viewModelScope 中执行、处理异常，并使用注入的应用级 Context 显示原生 Toast。页面不再启动操作协程或捕获业务异常，只调用动作方法，在完成回调中决定是否返回；不新增事件类型或事件流。

正常刷新保留内容与 Room 观察，读取异常后的刷新重新启动观察。删除进入 Loading 并暂停观察，失败恢复内容和观察。协程随导航条目的 ViewModel 清理而取消，取消继续抛出，不作为错误提示。ViewModel 不持有 Activity、页面 Context 或导航器。

导航条目现在各自持有独立 ViewModelStore，通过 LocalViewModelStoreOwner 供 hiltViewModel 获取页面实例；被覆盖时保留，出栈转场结束或导航宿主销毁时清理。仍沿用宿主的默认创建工厂与 CreationExtras，不新增进程重建或独立 SavedStateHandle 恢复能力。详情页错误重试改为重新扫描导航相册目录，而非仅重新订阅 Room；首次进入仍观察 Room。


相册库列表卡片按 EhViewer item_gallery_list_new 对齐：卡片外边距 2dp、圆角与阴影 2dp；左侧 80×120dp 封面按 1/3～4/3 比例范围裁剪，其余完整适配。右侧标题 16sp 最多两行，底部右侧以 14sp 显示阅读进度（上次浏览下标加一/总页数，例如 3/88）、容量及修改时间。文字采用常规字重、零额外字间距和自然行高，并保留 TextView 风格的字体上下留白；标题与次要文字分别使用主题正文色和次要文字色。保留本地长按多选及主题选中态。
